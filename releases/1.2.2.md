This release includes a bug fix - Attempting to delete an 'empty' set from the Tallies editor would cause the app to quit unexpectedly. 

If you observe app crashes or other issues with Moment Tally, please feel free to file an issue on Github https://github.com/sf1tzp/moment-tally and we'll try to resolve it ASAP. Thank you for using Moment Tally!

**A note on Moment Tally Server:** 1.2.2 is the last release that includes the self-hosted sync server. Moment Tally 2.0 brings the app to iPhone and iPad, and to deliver that experience well the app is staying simple: from 2.0 on, sync goes through iCloud only. If you sync through a server today, turn on iCloud sync in Settings after updating and your history carries over. Thank you to everyone who ran one!

**And on the Traggo import:** 1.2.2 is also the last release with the Import from Traggo path. Moment Tally began as a front end for Traggo, but it has long since stood on its own, and from 2.0 on the import is gone. If you still have history in a Traggo instance, import it before updating.
